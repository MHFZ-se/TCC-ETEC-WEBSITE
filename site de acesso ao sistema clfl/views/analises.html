Como interpretar os resultados

Entenda o significado dos status e das cores exibidas nas análises.

Normal

A leitura está dentro dos parâmetros definidos pelo sistema.

Atenção

A leitura merece uma verificação adicional.

Inconclusivo

Os dados não permitem uma classificação segura.

Cor detectada

Representa a cor registrada pelo sensor a partir dos dados RGB.

O que significa RGB? R representa vermelho, G representa verde e B representa azul. Cada componente normalmente varia de 0 a 255. A combinação dos três forma a cor exibida no cartão. A cor, isoladamente, não confirma uma deficiência ou doença da planta.
