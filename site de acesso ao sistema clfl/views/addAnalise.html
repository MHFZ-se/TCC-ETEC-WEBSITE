PLANTHEALTH / MONITORAMENTO

Iniciar monitoramento

Escolha como deseja registrar os dados das folhas. Utilize o sensor PlantHealth para iniciar uma coleta ou insira manualmente os valores de uma análise.

Conectar sensor

Inicie uma coleta utilizando o sensor para registrar os níveis de cor das folhas e encaminhar os dados para análise no sistema.

  • Coleta dos valores de cor RGB
  • Registro dos dados para consulta
  • Análise conforme os critérios do sistema

Cadastro manual

Já possui os valores de uma coleta? Registre o código do sensor, a cor observada e os níveis RGB para gerar uma análise.

  • Preenchimento manual dos dados
  • Ajuste dos canais vermelho, verde e azul
  • Registro no sistema PlantHealth
Cadastrar análise manualmente
Importante: a conexão automática depende da implementação da comunicação entre o sensor e o sistema. Se ela ainda não estiver configurada, utilize o cadastro manual.
