TECNOLOGIA DO PROJETO

Sensor TCS3200

O sensor de cor TCS3200 (ou TCS230) é um módulo programável que converte a intensidade da luz em frequência, permitindo identificar diferentes cores RGB.

Ele possui 64 fotodiodos com filtros para vermelho, verde, azul e sem filtro, sendo ideal para aplicações com Arduino, ESP32 e Raspberry Pi.
